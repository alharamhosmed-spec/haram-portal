# بوابة متقن لإدارة المشاريع — تطبيق

تطبيق ويب قابل للتثبيت (PWA) يغلّف نظام **أنظمة إدارة المشروع** المبني على Google Apps Script،
ويُستضاف مجاناً على **GitHub Pages**. يتثبّت على أندرويد وآيفون والكمبيوتر بأيقونة خاصة ويفتح بشاشة كاملة بدون شريط المتصفح.

© جميع الحقوق الفكرية محفوظة — مدير إدارة المشاريع: م. أحمد بندر الردادي
مستشفى الحرم · عقد التشغيل والصيانة غير الطبي

---

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الغلاف: شاشة إقلاع + إطار النظام + شاشة «لا يوجد اتصال» + زر التثبيت |
| `manifest.webmanifest` | اسم التطبيق وأيقوناته وألوانه |
| `sw.js` | يخزّن الغلاف فقط ليفتح بسرعة (لا يخزّن أي بيانات) |
| `icon-*.png` · `apple-touch-icon.png` · `favicon-32.png` | الأيقونات (في نفس المكان، بدون مجلد) (192 / 512 / maskable / آيفون / favicon) |
| `tools/make_icons.py` | مولّد الأيقونات (اختياري) |
| `.nojekyll` | يمنع GitHub من معالجة الملفات |

## خطوات التشغيل (مرة وحدة)

### 1) جهّز نظام Google Apps Script
- في `Code.gs` تأكد أن `doGet` فيه: `.setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL)` ✅ (موجود في v2.0.0).
- **نشر ← إدارة عمليات النشر**:
  - التنفيذ باسم: **أنا**
  - من يمكنه الوصول: **أي شخص** (Anyone)
  > إذا اخترت «أي شخص لديه حساب Google» ما راح يفتح داخل التطبيق، لأن Google تمنع شاشة تسجيل الدخول حقها داخل الإطارات.
- انسخ رابط النشر اللي ينتهي بـ `/exec`.

### 2) حط الرابط في `index.html`
```js
GAS_URL: 'https://script.google.com/macros/s/XXXXXXXX/exec',
```
هذا هو السطر الوحيد اللي يتغيّر.

### 3) ارفع على GitHub
1. github.com ← **New repository** ← الاسم: `haram-portal` ← Public ← Create.
2. **Add file ← Upload files** ← اسحب كل محتوى المجلد (كل الملفات في مكان واحد، بدون مجلدات) ← Commit.
3. **Settings ← Pages** ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقة إلى دقيقتين يصير الرابط:
   `https://<اسم-حسابك>.github.io/haram-portal/`

### 4) التثبيت على الأجهزة
- **أندرويد (Chrome)**: افتح الرابط، يطلع زر «تثبيت التطبيق»، أو من القائمة ⋮ ← «تثبيت التطبيق».
- **آيفون (Safari)**: زر المشاركة ← «إضافة إلى الشاشة الرئيسية». التطبيق نفسه يعرض هذا التلميح أول مرة.
- **الكمبيوتر (Chrome / Edge)**: أيقونة التثبيت في شريط العنوان.

## التحديثات
- **تعديل النظام نفسه** (Code.gs / Index.html في GAS): انشره كـ «نسخة جديدة» **على نفس عملية النشر** عشان يبقى الرابط نفسه، وما تحتاج تلمس GitHub.
- **تعديل الغلاف** (الاسم، الأيقونة...): عدّل الملف على GitHub، وزِد رقم `VERSION` في `sw.js`.

## تغيير الأيقونة
```bash
python3 tools/make_icons.py cross   # cross | box | shield | doc | wrench | user | drop | key | grid
```

## ملاحظات
- التطبيق يحتاج اتصال إنترنت لأن البيانات في Google Sheets. بدون اتصال تظهر شاشة واضحة، ويرجع تلقائياً أول ما يرجع الاتصال.
- على آيفون ممكن Safari يمنع حفظ الجلسة داخل الإطار، فيطلب منك رمز الدخول عند كل فتح جديد للتطبيق. هذا سلوك من Safari نفسه وما يأثر على البيانات.
- المستودع لازم يكون Public عشان GitHub Pages المجاني. ما فيه أي سر في هذه الملفات، كلها واجهة فقط، والرمز والبيانات تبقى في Google.
- **تطبيق APK للمتجر (اختياري لاحقاً)**: ادخل [pwabuilder.com](https://www.pwabuilder.com) وحط رابط GitHub Pages، يطلع لك حزمة أندرويد جاهزة.
