# نقاء — تطبيق نظافة دورات المياه والنفايات غير الطبية

غلاف تطبيق (PWA) لنظام **نقاء** المبني على Google Apps Script — بنفس «نمط التطبيق» حق بوابة الحرم.
يتثبّت على أندرويد وآيفون والكمبيوتر بأيقونة القطرة ويفتح بشاشة كاملة.

**رابط التطبيق:** `https://alharamhosmed-spec.github.io/haram-portal/naqaa/`

© جميع الحقوق الفكرية محفوظة — مدير إدارة المشاريع: م. أحمد بندر الردادي · مستشفى الحرم

## الإعداد (مرة وحدة)
1. نظام نقاء **v1.5.2 أو أحدث** (فيه `setXFrameOptionsMode(ALLOWALL)` ووضع التطبيق).
2. النشر: التنفيذ باسم **أنا** · الوصول **أي شخص**.
3. حط رابط `/exec` في `naqaa/index.html`:
   ```js
   GAS_URL: 'https://script.google.com/macros/s/XXXXXXXX/exec',
   ```

## مزايا خاصة بنقاء
- **فتح دورة أو حاوية مباشرة:** `…/naqaa/?r=WC-HOS-001` أو `?b=BIN-HOS-001` — الغلاف يمرّر الرقم للنظام (بصيغة مقيدة فقط).
- **«دخول النظام» داخل التطبيق** ينقلك لشاشة الدخول في مكانها بدل ما يفتح رابط خارجي يطلّعك من التطبيق.
- التخزين المحلي للغلاف ببادئة `naqaa_` حتى ما يتداخل مع البوابة (نفس النطاق).

## التحديثات
- تعديل النظام نفسه: انشره كـ **New version على نفس النشر** — ما تحتاج تلمس GitHub.
- تعديل الغلاف: عدّل الملف وزِد `VERSION` في `naqaa/sw.js`.
- الأيقونة: `python3 tools/make_icons.py drop naqaa`
